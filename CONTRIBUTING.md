# Contributing

Plain-language summary: suggestions, bug reports and new benchmark methods are welcome.

- **Bugs and questions:** open a GitHub issue with what you ran, what you expected and what happened.
- **New leaderboard entries:** follow "Submit a method" in the README, pass a link to your code with `--url`, and open a pull request that adds your row to `benchmark/leaderboard.csv`.
- **Measured spectra:** if you can share measured spectra of real green sand components or mixtures (with composition and instrument details), open an issue. Measured data are the most valuable contribution.
- **Code changes:** run `pytest` before opening a pull request; keep numbered scripts runnable in order.
