Green Sand NIR Detection-Limit Leaderboard

Which additive levels can a near-infrared method actually detect in foundry green sand? Every method is scored by one rule: the alarm is set so at most 5% of clean sand samples trigger it, and the detection limit is the lowest additive level caught in at least 95% of samples, at that level and every level above it. Spectra are computed (Hapke mixing of USGS splib07 reference spectra, calibrated to measured lab data), resampled to a 1000-2350 nm InGaAs instrument.

Noise tiers: ideal (signal-to-noise 10000:1, no packing effects); lab (2000:1, 1% packing gain variation); plant floor (500:1, 3%). Tracks: dry sand; moist sand (2-5% water). Levels are percent of the dry mix.

Submit a method

Download a set from benchmark/sets/, train on the _calibration file, score every row of the _test file (higher score = more additive; do not use the test composition columns), then run python code/score_submission.py --set <set name> --scores your_scores.csv --method "name" --submitted-by "you" --append and open a pull request. Test labels are public, so the leaderboard runs on trust; methods are expected to share code.
